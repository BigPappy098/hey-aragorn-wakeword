# Hey Aragorn Wake Word Model

Trained microWakeWord model for "Hey Aragorn" wake word detection.

## Files

- `last_weights.weights.h5` - Trained model weights (10,000 steps)
- `training_parameters.yaml` - Training configuration
- `model_output/hey_aragorn.tflite` - Converted TFLite model (generated by CI)

## Usage

The TFLite model is generated via GitHub Actions. To trigger conversion:

1. Go to **Actions** tab
2. Select **"Convert Wake Word Model to TFLite"**
3. Click **Run workflow**
4. Wait ~10 minutes
5. Download the model from the workflow artifacts or find it in `model_output/`

## ESPHome Integration

Add to your ESPHome config:

```yaml
micro_wake_word:
  models:
    - model: hey_aragorn
      probability_threshold: 0.7  # Adjust based on testing
```

## Training Details

- **Target word:** hey_air_uh_gorn (phonetic spelling)
- **Samples:** 1000 TTS-generated wake word samples
- **Training steps:** 10,000
- **Architecture:** MixedNet (26K parameters)
- **Quantization:** INT8 for ESP32
